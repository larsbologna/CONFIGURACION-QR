Generador de QR

Conectar con GitHub (una sola vez por dispositivo)

Para crear QR o cambiar links, esta página necesita una llave de tu cuenta de GitHub. Se guarda solo en este navegador: en la compu y en el celular se pega por separado. Si ya tenés una llave, pegá la misma (no hace falta crear otra).

¿No la tenés a mano? Creá una nueva con estos pasos:

  1. Abrí este link (tenés que estar con tu cuenta de GitHub).
  2. En Token name poné Generador QR. En Expiration elegí la fecha que quieras (por ejemplo, 1 año).
  3. En Repository access elegí Only select repositories y marcá CONFIGURACION-QR.
  4. En Permissions → Repository permissions → Contents elegí Read and write.
  5. Abajo de todo tocá Generate token, copiá la llave (empieza con github_pat_) y pegala acá:

Nuevo QR

Pegá el link a donde tiene que llevar el QR. El sistema le asigna el próximo número libre y te arma el diseño listo para el local.
